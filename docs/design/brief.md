# 星光树洞 · 视觉与交互约定

- 用户提供的蓝色油画棒插画为风格源，横屏扩展构图见 `scene-concept.png`。
- 电脑优先、背景铺满屏幕。图层、透视、光影和鼠标视差组成 2.5D 场景。
- 夜空 / 地面：蓝青 `#225775`、钴蓝 `#245b85`；黑炭 `#101b24`；文字暖奶油 `#f7e4ad`；黄光 `#ffe16e`；日记纸面 `#f4ecd7`。
- 本机楷体 / 宋体回退；少量文字；标题 28–48px、正文 16–20px；全幅插画，无卡片网格。
- 基准 16:9：书偏右上；三颗大星位于左上、左中下、右下。背景、书、星星、女孩、投射光独立；标题和提示为 HTML。
- 初始女孩蹲下、竖立书本的正面书页暗淡可见、三颗大星暗淡。用户圈出的正面是书页，不是封面。
- 点击书后约 6.8 秒：起身 → 走向书本 → 抵达后书页与投射光渐亮 → 星光逐次亮起 → 自动跳转 `#/diary`。书本形态不变，没有翻页或开合动作。
- 星星悬停 / 键盘聚焦时平滑变大、点亮；离开恢复当前场景的基础光泽与大小。
- 三颗星跳转 `#/stars/1`、`#/stars/2`、`#/stars/3` 占位。日记为真实可用的本地日记。
- 返回星空后回到初始状态并允许重播；动画防重入、卸载清理；支持键盘、历史导航、减少动态。
- 内置 Image Gen 依据原图生成透明素材。提示词在 `docs/design/prompts`。背景在概念图基础上移除动态物体、光路及文字，保留蓝色笔触、黑星与星屑。

## 心情日记 · 2026-10-03

- 参考用户双页草图，视觉概念 `diary-concept.png`。既有深蓝油画棒背景、奶油纸页、楷体标题和细线天气图标组成统一视觉。
- 主界面：左上「回到星光里」，标题「心情日记」与「把今天的心事，轻轻写在这里。」，右上「添加日记」。中央日期范围、双页日记本、每页 5 条记录、下方分页。
- 每页三个列头「日期」「今天的心事」「心情天气」。日期蓝色 #3d7198，摘要灰色 #595961，天气粉色 #9d526e；纸面 #fbf4e3，星空 #1d455b。正文 16–18px，控件 14–16px，标题 40–50px；日期等宽数字。天气使用相同线宽的 SVG 图标。
- 透明摊开本子作独立装饰背景，真实 HTML 行与表单叠在纸面上，左页/右页安全区分别约 x6–47% / x53–94%，内容区域 y12–87%。无卡片网格。
- 新增、编辑延续同一个双页本：左页日期和日记正文，右页自动心情天气与手动选择。顶部明确保存及返回操作；未保存内容离开前确认。
- 初次使用为空白本，无伪造日记。日记按日期倒序分页；每天一篇，同日已有日记时引导编辑。文本最多 2000 字。天气为文字线索生成的心情比喻，允许调整。
- 用户确认本阶段使用当前浏览器本地保存，不接账号/服务器。保存失败不能显示成功，不覆盖无法解析的已有数据。
